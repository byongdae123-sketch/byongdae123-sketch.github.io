## Publish on GitHub Pages

1. Create a **public** repository named `byongdae123-sketch.github.io` on your GitHub account. Initialize with a README to create the `main` branch.
2. Upload the **contents of this folder** (not the folder itself) into the repository root using `Add file > Upload files`, or use the connected ChatGPT GitHub tools to add them after the repository exists.
3. Open repository `Settings > Pages > Build and deployment`.
4. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** and save.
5. Visit `https://byongdae123-sketch.github.io/` after GitHub finishes deploying.
